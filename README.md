# 🛍️ E-Commerce Frontend Website

This is a responsive and modern **E-Commerce frontend** built with **React** and styled using **Tailwind CSS** (or any other framework you used). It features product listings, filtering, sorting, cart functionality, and more.



## 🚀 Features

- Product grid and list views
- Category, color, company filters
- Sort by price and name
- Add to cart & adjust quantity
- Product detail page
- Responsive design
- Clean UI and component-based architecture

---

## 🛠️ Tech Stack

- **React**
- **Tailwind CSS** / CSS Modules / Styled Components
- **React Router**
- **Context API + useReducer**
- **FakeStoreAPI / custom backend mock**
